# Projektregeln

- `README.md` auf das Nötigste beschränken: Kurzbeschreibung, Feature-Stichpunkte, Voraussetzungen, Startbefehle, kurze MCP-Verbindungsanleitung und Links.
- Jedes Feature nur als kurzen Stichpunkt nennen. Keine ausführlichen Feature-Erklärungen oder Änderungsberichte aufnehmen.
- Nötige MCP-Befehle und Verbindungskonfiguration dürfen in der README stehen.
- Details bei Bedarf in `docs/` ablegen und aus der README nur knapp verlinken.
